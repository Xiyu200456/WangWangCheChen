Analytical Approach

We used Pearson correlation analysis to examine the relationship between China’s solar PV panel exports and annual solar PV capacity additions across North and South American countries.

This approach was selected to answer one of the supporting questions of our research theme: Is there a correlation between China’s solar panel export capacity (MW) and annual solar PV capacity additions (MW) in destination countries?

We first calculated the overall correlation and then conducted separate analyses for North and South America to compare regional patterns.

Data Validation and Diagnostics

Before conducting the analysis, we checked for duplicate observations, missing values, and the accuracy of annual capacity additions calculations.

We identified 15 missing values in annual capacity additions, all from 2018. These observations were excluded, leaving observations from 2019 to 2025.

# Leave-one-country-out influence analysis

countries <- df %>%
  distinct(Study_scope, Area)

influence_results <- purrr::map2_dfr(
  countries$Study_scope,
  countries$Area,

  function(region, country) {

    # Original regional data
    region_data <- df %>%
      filter(Study_scope == region)

    # Remove one country
    reduced_data <- region_data %>%
      filter(Area != country)

    # Calculate correlations
    r_original <- cor(
      region_data$China_panel_exports_MW,
      region_data$PV_capacity_additions_MW
    )

    r_without <- cor(
      reduced_data$China_panel_exports_MW,
      reduced_data$PV_capacity_additions_MW
    )

    tibble(
      Region = region,
      Country_removed = country,
      Original_r = r_original,
      Without_country_r = r_without,
      Change_in_r = r_without - r_original,
      Absolute_change = abs(r_without - r_original)
    )
  }
)

# Rank countries by influence within each region

  group_by(Region) %>%
  arrange(desc(Absolute_change), .by_group = TRUE) %>%

# Function to calculate Pearson correlation

calculate_cor <- function(data, scenario) {

  tibble(
    Scenario = scenario,
    N = nrow(data),
    Countries = n_distinct(data$Area),
    Pearson_r = cor(
      data$China_panel_exports_MW,
      data$PV_capacity_additions_MW
    )
  )
}

Results and Sensitivity Analysis

The overall Pearson correlation was r = 0.354, indicating a moderate positive linear association.

However, the regional results differed substantially:

North America: r = −0.013, indicating almost no pooled linear correlation.

South America: r = 0.986, indicating a very strong pooled positive correlation.

To evaluate the robustness of these findings, we conducted a sensitivity analysis by excluding major markets.

Excluding the United States increased the North American correlation from −0.013 to 0.823, while excluding Brazil decreased the South American correlation from 0.986 to 0.842.

These results suggest that major national markets have a substantial influence on the observed regional correlations.

Limitation of sensitivity analysis: North American correlations are generally sensitive to the exclusion of individual countries due to the region’s small number of countries.
